## 2.ความเข้าใจโจทย์ของฉัน

อธิบายโจทย์: โจทย์นี้จะให้สร้างโปรแกรมการคำนวณว่ากระเบื้องขนาด N * N แผ่นมีจุดไหนที่เป็นข้อบกพร่องและมีกี่จุดจากนั้นนำไปหาว่าแต่ละแถวมีข้อบกพร่องกี่ตำแหน่ง, รวมแล้วมีกี่จุดและหาของแต่ละหลักด้วยเช่นกันแล้วจึงหาว่ารวมแล้วมีข้อบกพร่องกี่ตำแหน่ง, รวมทั้งหมดกี่จุด, เป็นค่าปรับรวมเท่าไหร่

Input: 

    บรรทัดที่ 1: ขนาดของ N, ค่าปรับในแต่ละจุด
    บรรทัดที่ 2 - N+2: รายละเอียดในแต่ละแถวว่าตำแหน่งไหนมีข้อบกพร่องที่จุด

Output: 

    บรรทัดที่ 1 - N: รายละเอียดของกระเบื้องในแต่ละแถวมีต่อท้ายด้วย ตำแหน่งทั้งหมดที่มีข้อบกพร่อง, มีข้อบกพร่องในแถวนั้นรวมทั้งหมดกี่จุด
    บรรทัดที่ N + 1: จำนวนตำแหน่งที่มีข้อบกพร่องในแต่ละหลัก
    บรรทัดที่ N + 2: จำนวนจุดทั้งหมดที่มีข้อบกพร่องในแต่ละหลัก
    บรรทัดที่ N + 3: จำนวนตำแหน่งทั้งหมดที่มีข้อบกพร่อง, จำนวนจุดทั้งหมดที่มีข้อบกพร่อง, ค่าปรับทั้งหมด

Constraints: 

ต้องหาวิธีในกาต่อท้ายข้อมูลของตำแหน่งทั้งหมดที่มีข้อบกพร่อง, มีข้อบกพร่องในแถวนั้นรวมทั้งหมดกี่จุดในแต่ละบรรทัดของบรรทัดที่ 1 - N

## 3.แผนแรกของฉัน

ขั้นแรก: รับค่าของขนาด N, ค่าปรับในแต่ละจุด

ขั้นที่สอง: รับค่าของแต่ละแถวมาและนำไปเก็บเป็น list

ขั้นที่สาม: สร้าง for loop สำหรับคำนวณตำแหน่งทั้งหมดที่มีข้อบกพร่อง, มีข้อบกพร่องในแถวนั้นรวมทั้งหมดกี่จุดและเก็บข้อมูลจำนวนตำแหน่งทั้งหมดที่มีข้อบกพร่อง, จำนวนจุดทั้งหมดที่มีข้อบกพร่องในนั้นด้วยเพราะครอบคลุมทุกแผ่นแล้ว

ขั้นที่สี่: สร้าง for loop สำหรับจำนวนตำแหน่งที่มีข้อบกพร่องในแต่ละหลักและจำนวนจุดทั้งหมดที่มีข้อบกพร่องในแต่ละหลัก

ขั้นที่ห้า: แสดงผลออกมาเหมือนกับที่อธิบายใน output
