## 2.ความเข้าใจโจทย์ของฉัน

อธิบายโจทย์: โจทย์นี้จะให้สร้างโปรแกรมคำนวณว่าของขวัญชิ้นนี้จะมีคนได้พิจารณากี่คนจากคนจำนวน N คนที่นั่งล้อมเป็นวงกลมอยู่ โดย 1 ในนั้นจะเป็นหัวขโมย ส่วนแรกของขวัญจะอยู่ในตำแหน่งที่ 1 จากนั้นให้ส่งต่อกันไปเรื่อยๆตามจำนวนโดยหากส่งต่อไปถึงตำแหน่งของหัวขโมยให้จบการทำงานทันทีและนับหัวขโมยรวมในจำนวนคนที่ได้พิจารณาของขวัญด้วยหรือถ้าหากของขวัญชิ้นนี้กลับมาอยู่ในตำแหน่งที่ 1 ก็จะจบการทำงานเช่นกัน (แต่จะไม่นับรวมอยู่ในคนที่ได้พิจารณาของขวัญ)

Input: 1.จำนวนเต็ม 3 จำนวนประกอบด้วย (จำนวนคนทั้งหมด, ระยะห่างในการส่งของขวัญในแต่ละครั้ง, ตำแหน่งของหัวขโมย)

Output: จำนวนคนทั้งหมดที่ได้พิจารณาของขวัญ

Constraints: หากของขวัญถูกส่งต่อไปถึงตำแหน่งของหัวขโมยให้จบการทำงานทันทีและนับหัวขโมยรวมในจำนวนคนที่ได้พิจารณาของขวัญด้วยหรือถ้าหากของขวัญ
ชิ้นนี้กลับมาอยู่ในตำแหน่งที่ 1 ก็จะจบการทำงานเช่นกัน (แต่จะไม่นับรวมอยู่ในคนที่ได้พิจารณาของขวัญ)

ขั้นที่สี่: แสดงผลออกมาว่าจำนวนคนที่ได้พิจารณาของขวัญมีกี่คน
