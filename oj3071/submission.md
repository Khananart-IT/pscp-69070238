## 2.ความเข้าใจโจทย์ของฉัน

อธิบายโจทย์: โจทย์นี้จะให้สร้างโปรแกรมให้หาว่าตัวเลขตั้งแต่ A ถึง B มีตัวที่สามารถหาร C ได้เศษ D ได้กี่จำนวนโดยที่ B > A โดยที่ตัวแปรทั้งหมดจะเป็นจำนวนนับ

Input: 
        
        1.จำนวนตัวเลขตัวแรก (A)
        2.จำนวนตัวเลขตัวที่สอง (B)
        3.ตัวหารที่ต้องการ (C)
        4.เศษที่ต้องการ (D)

Output: แสดงจำนวนเลขตั้งแต่ A ถึง B มีตัวที่สามารถหาร C ได้เศษ D ได้กี่จำนวน

Constraints: โจทย์ได้กำหนดมาว่า B > A และ C > D

## 3.แผนแรกของฉัน

ขั้นแรก: สร้างฟังก์ชันที่ไว้สำหรับคำนวณตัวเลขของ output ที่ต้องการโดย input ทั้งหมดจะอยู่ในฟังก์ชันนี้

ขั้นที่สอง: สร้างตัวแปร need_amount สำหรับเก็บข้อมูลจำนวน output ที่ค้องการ

ขั้นที่สาม: สร้าง for loop สำหรับการคำนวณตัวเลขของ output ที่ต้องการโดยมีขอบเขตตั้งแต่ตัวเลข A ถึงตัวเลข B + 1 หากครบเงื่อนไขที่ต้องการจะเพิ่มตัวแปร need_amount ขึ้นมาทีละ 1

ขั้นที่สี่: แสดงผล output ผ่านตัวแปร need_amount
