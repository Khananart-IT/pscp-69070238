## 3.แผนแรกของฉัน

ขั้นแรก: สร้างตัวแปร start และ finish ผ่านฟังก์ชัน map เพื่อจะได้ไม่ต้องประกาศตัวแปรซ้ำอีกรอบ (ข้อมูลตัวแปรจะมาจาก input)

ขั้นที่สอง: สร้าง dict ขึ้นมาเพื่อตรวจสอบว่าต้นทางและปลายทางมีอยู่ในเส้นทางการจัดส่งหรือไม่โดย key จะเป็น list ของ start และ finish รวมกัน [start, finish] (ราคาค่าธรรมเนียมจะอยู่ใน value)

ขั้นที่สาม: คิดค่าธรรมเนียมการจัดส่งโดยใช้ list จาก value จาก key ที่เป็น list ของต้นทางและปลายทาง

ขั้นที่สี่: แสดงผล output ออกมา
